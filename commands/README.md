# Executed commands

`completed-cloud-runs.md` records the exact top-level invocations used for the
eighteen primary runs and the environment-independent command pattern that
each invocation expands to. The corresponding runtime, GPU, thresholds, image
cap, and raw-record SHA-256 values are recorded in `results/summary.csv`.

This repository deliberately excludes cloud-provider identifiers, login
commands, private storage paths, credentials, datasets, checkpoints, and raw
prediction files. Do not add them to version control.
